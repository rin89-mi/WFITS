# WFITS Project

美容室 **WFITS** の公式Webサイトとして制作したポートフォリオ作品です。
実在店舗を想定し、**企画・デザイン・コーディングまで一貫して担当**しました。

---

## Overview

- 1席のみのプライベートサロンを想定したWebサイト
- 落ち着いた世界観と視認性を重視したデザイン設計
- PC / スマートフォン両対応のレスポンシブ実装

---

## Purpose

本制作は、以下のスキルを意識して取り組みました。

- クライアント要件を想定した情報設計
- ユーザー導線を意識したUIデザイン
- HTML / CSS（Sass）による保守性のあるコーディング
- JavaScriptによるアニメーション表現の実装

---

## Tech Stack

- HTML5
- CSS3 / Sass
- JavaScript（Vanilla JS）
- CSS Grid / Flexbox
- Responsive Design

## Key Features

- 固定ヘッダーによるナビゲーション設計
- フェードアップアニメーションによる視線誘導
- pictureタグを用いたデバイス別画像切り替え
- Google Maps の埋め込みによる店舗情報の可視化
- スマートフォン時の操作性を考慮したUI設計

---

## Responsive Design

- ブレークポイント：**440px**
- デバイスごとに最適化されたレイアウト
- スマートフォンではナビゲーションを簡略化
